状态与文案

任务状态

显示状态 语义 图形与颜色方向
待处理 任务已存在，尚未执行或结束 中性空圆
执行中 确有活跃执行 开口环、蓝色
需要处理 有需用户处理的具体原因 提示符号、黄褐色
待验收 已提交结果，等待用户确认 检查文档、蓝色
已完成 用户接受当前结果版本 圆形勾、绿色
已取消 任务取消，历史保留 圆形叉、中性色

产品状态为 open / review / completed / cancelled；执行中与需要处理结合运行事实投影，不另造一套互相冲突的任务状态机。

独立维度

维度 例子 不能混淆的含义
设备连接 在线、离线、连接中 离线不等于任务失败
模型认证 已连接、需登录、验证失败 有连接不等于有可执行模型
消息投递 本机已保存、待连接、已接收 已接收不等于执行开始
未读 有尚未阅读的可见消息 不按运行状态推测未读
文件可用性 本机可查看、待同步、不可用 不可下载不等于整个任务消失

未读由消息 ID 与本机已读记录判断，显示计数或小标记，不改变字体粗细。后台运行与未读不能共用一个圆点语义。

文案基准

  • 使用“添加设备”“模型连接”“手动添加模型”“待配置模型”。
  • 错误描述具体问题，并给出下一步，例如“此连接尚未添加模型”。
  • 离线提示说明已保存内容仍可查看；需要联网的操作给出等待或重试状态。
  • 不用“已完成”代替“运行结束”；不把按钮点击写成操作已成功。
  • 产品名是 Zork；Leader / Worker / Task 的用词保持一致。
  • 示例消息、版本与授权流程明确标记为样稿，不暗示已经接入真实账号。

空状态

空状态先说明“这里是什么”，再给一个主要行动。无 Leader 引导创建 Leader；无模型引导获取或手动添加；收件箱为空不制造错误感。不要在每个空列表重复放大型吉祥物和宣传口号。
