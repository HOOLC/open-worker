动物头像生成规范

这份文档用于持续新增同一系列的 Zork Agent 头像。现有 12 个 SVG 是风格基准；生成的新图先作为候选，再经过小尺寸检查进入素材库。

现有头像 · 头像配色与结构数据 · 可复用提示词

核心风格

正面、半身以上的动物头部图形，表情平静而友善。用少量平面色块概括动物特征：浅色圆角底、一个主体色、一个次级面部色、深色五官。整体接近简洁的矢量插画，不画毛发纹理、强高光、拟真立体、完整身体或复杂场景。

不同动物靠耳朵、脸型、面部区域、鼻口特征区分。不要靠帽子、眼镜、职业服饰或文字标签区分。头像代表个体，不把 Leader / Worker、忙碌、离线或错误画进头像。

固定画布

参数 基准与容许范围
SVG 母版 viewBox="0 0 64 64"，导出画布 256×256
背景 x=0 y=0 width=64 height=64 rx=18
对称轴 x = 32；允许为表情作轻微光学调整
主体范围 通常 x=10–54，y=12–56；长耳/冠羽可延伸，但保留背景余量
眼睛中心 通常 x=24、40，y=31–33
标准瞳孔 rx=1.9 ry=2.35；狐狸等可轻微扁化/倾斜
鼻口中心 x=32，通常 y=38–47；按吻部长度调整
细节描边 64 单位母版上约 1.6–1.9，圆端点、圆连接
常用显示尺寸 导航 20 px，消息 26 px；新增时还要检查 16 / 32 / 48 px

这些是从现有系列提取的范围，不要求把鹿角、兔耳和章鱼硬塞进同一个头部轮廓。视觉重量与脸的位置保持一致，轮廓允许体现物种差异。

形状与层次

按以下顺序组织 SVG：

  1. 浅色圆角背景。
  2. 耳朵、冠羽或头部外轮廓；以圆滑曲线为主。
  3. 面罩、口鼻或耳内的次级色块。
  4. 双眼、鼻子及一条必要的口部线。
  5. 最多一组确有物种辨识作用的小特征，例如鹿角、熊猫眼圈或章鱼触足。

不要给所有外轮廓加粗黑描边。描边主要用于嘴部、短胡须或少量内部细节。新动物的耳尖、喙或角可以保留方向性，但尽量圆滑衔接，避免尖刺感。旧头像中的几何转角是历史基准，不要求复制每一处尖点。

配色

深色五官统一使用 #29323D；必要的暖白使用 #FFFDF9。每个头像通常使用 3–5 种颜色，靠明度区分面部层次，避免渐变、发光和投影。

示例 背景 主体 次级色
猫 #EEF1F7 #657EA7 #DFE7F3
狐狸 #FFF0E8 #D67B47 #FFE4C9
猫头鹰 #EFF3E9 #7E906F #DFE8D4
章鱼 #F5ECF3 #AA80A4 #EAD8E7

新增动物可用新的低饱和色族，但应先与 12 个基准并排比较。背景保持浅、主体保持中等明度、五官保持最深。橙色不是所有动物必须具备的品牌点缀，也不承担状态语义。

生成一只新动物

先选一个明确的动物和两个最有辨识度的特征，例如“海豹：圆头 + 短吻”。从最接近的现有 SVG 学习构图，另选两个头像控制系列感；不要把参照动物的整张脸仅换颜色当作新头像。

给图像模型附上至少 3 个原始头像，使用 生成简报。图像生成结果用于确认方向。交付 SVG 时应重新组织为清晰的可编辑路径，不能把 PNG 内嵌进 SVG 冒充矢量。

使用代码或矢量工具直接制作时，沿用同一网格、颜色角色与分层顺序。先完成单只，再检查整组；不要一次扩张几十只后才发现风格跑偏。

验收清单

  • 在 20 / 26 px 仍能看清双眼，动物轮廓有辨识度。
  • 与猫、狐狸、熊猫、猫头鹰并排时，头部大小、五官位置和细节密度协调。
  • 没有毛发噪点、装饰道具、字母、角色徽标或状态圆点。
  • 背景半径、画布尺寸和输出留白与系列一致。
  • 轮廓没有意外尖刺、自交、裁切或极细缝隙。
  • SVG 不含脚本、外部图片、嵌入位图、外部字体或滤镜依赖。
  • 文件名采用稳定的小写英文动物 ID；已有 ID 不重命名。
  • 记录配色、来源、日期与评审状态，再更新 manifest 和预览图。
