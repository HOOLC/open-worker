移动端规范

当前版本为 nav7 / 2026-09-06，来自“设计 Zork 移动端 App”任务。当前依据为移动端规范与可操作 HTML；最初三屏图片保留作历史概念。

移动端设计入口 · 完整规范 · 打开原型 · 验证记录

与桌面共享的部分

设备 → Leader → Task 的产品关系；稳定的人物身份；按设备管理 Agent 与模型连接；选中文字后积累评论、最后一次发送；颜色和字体不随 active / unread 改变；状态背景整行同宽，缩进只改变内容。

桌面数值不是全平台硬性尺寸。移动端采用本表与 mobile-tokens.json，不能直接套用 30 px 行高、可拖动侧栏或常驻选中背景。

按压与返回

整个导航行负责绘制背景，Leader 名称和展开按钮保持各自操作。抬手、拖动、滚动、取消或页面失焦均清除按压状态。设备设置列表与顶部设备入口也遵守同一规则。

从 Task / Leader 聊天进入设备设置后，设备页及其 Agent、模型子页记住来源；“返回对话”恢复原草稿和阅读位置。从设置首页进入设备则返回设置首页。

素材与来源

移动原型保留自包含素材快照，便于独立预览；统一素材库仍是上级 assets。快照与统一素材的逐项关系、哈希和是否一致记录在 素材映射。重复使用的素材不重复计入总素材数量。

移动版目前使用 Zork 文字标识，没有套用仍在探索的折角字标和品牌动画。初版概念图与概念说明属于历史资料。

验证状态

来源任务的 DOM 交互检查与静态资源检查已通过。实际手机触摸、系统键盘、选择手柄和修订后的浏览器截图尚未复核；这些保持待验证，不写成已经通过视觉验收。此处为设计原型，未连接真实模型或设备。
