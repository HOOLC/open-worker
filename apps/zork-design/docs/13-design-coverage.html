来源与复用

当前参考实现位于 src/reference/，是根据本轮补齐范围更新的 React 设计稿；旧 HTML 原型仍保留为历史材料。它们有不同的来源标记，当前设计稿不冒充早期原稿。

crates/zork-ui/assets/stories/page-fixture.json 同时提供两侧初始数据。React 的颜色与基础尺寸从公共 GPUI 常量读取。原生截图记录实际 Metal 输出，参考截图记录实际浏览器输出；每次导出保留来源文件哈希、参数与裁切范围。

原生应用、基础组件示例及 Web 页面共用 crates/zork-ui/ 的公开组件。该包不依赖 Gateway、网络服务或应用数据库。账号、设备、组网、弹窗、历史事件行、评论和附件的正式界面均使用这些公共组件。

验证与范围

页面遍历检查所有 58 个页面、19 个组件类别、5 个外层页签、窄窗口、重置及四种对照模式。实际指针/键盘验证覆盖 Switch、菜单、输入框、表单校验、评论、头像、历史、附件和弹窗；另以原生窗口检查桌面业务流程。

证据保存在 zork 的 artifacts/storybook/design-completion/，包括页面截图、交互结果、覆盖计划与交付记录。构建和原生测试日志见交付记录。

会话整页的 GPUI 一侧使用实际原生快照；历史、评论、附件等公共组件拥有独立可交互 Web 示例。原生完整会话的服务集成不在浏览器中模拟。移动端完整组件库与深色主题沿用独立范围。
