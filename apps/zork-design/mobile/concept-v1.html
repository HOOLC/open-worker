Zork 移动端 App 设计 v1

日期：2026-09-06。交付：zork-mobile-v1.png，一套方案的三个页面：对话导航、任务群聊、设备设置。静态视觉稿，非已实现的移动客户端。图中消息、设备状态、数量、文件附件均为演示内容。

设计依据

  • 品牌设计任务 01a0746f-8901-7a00-832a-1875d975cf0f 的最新要求、用户提交的桌面截图。
  • ../brand-review-site/src/gui/README.md、gui/tokens.css、gui-mockups/brief.md。
  • 生成输入实际附带品牌总览、12 个头像总览、桌面 GUI 截图。
  • 最新名称采用 Zork，覆盖旧品牌提案的小写字标。

移动端方案

  1. 导航独占一屏，保留设备 → Leader → Task。任务无重复图标与消息摘要；未读由计数表达。底部放添加设备与设置入口。触摸区域按至少 44px 设计；选中状态不改变字重。
  2. 点进任务后全屏阅读群聊。顶部仅保留返回、成员头像、设备。自己的消息无头像或姓名；文件留在消息流中。返回后应恢复导航与阅读位置。
  3. 长按选中消息片段后添加评论，暂存于输入框上方，可重复添加、编辑和移除，最后与正文一起发送。输入框自动增高；键盘出现时输入区随键盘上移。键盘状态与评论编辑状态尚未绘制。
  4. 设置使用逐层进入的导航。mini1 页面配置远端设备本身，其后台运行、登录后启动不代表手机后台运行能力。Agent 与模型连接均归属该设备。保留手动配置与 Leader 协助。
  5. 添加模型连接沿用订阅账号 / API 接入 → 供应商 → 认证的既有流程，模型在连接详情另行管理；本轮未绘制该子流程。

生成方法与最终提示词概要

使用内置 ImageGen，一次生成一套连续三屏方案，非三个不同风格。参考单屏逻辑尺寸 390×844；生成排版为视觉概念，非可直接用于像素验收的精确尺寸稿。

提示词要求：production-quality mobile UI；三屏等比例并排，仅显示应用内容，无设备壳、系统状态栏或外部宣传文案。沿用折角伙伴标志与 fox / cat / panda / dog / owl 原头像；暖纸 #F6F3EA、白底、炭墨 #24272B、次级文字 #62656B，柿橙仅少量强调；中文正文 15–16px、辅助文字 12–13px、至少 44px 触摸区域、紧凑低高度页头。以留白与对齐区分内容，避免重边框、阴影、渐变、嵌套卡片和仪表盘指标。

左屏：Zork 标识，mini1 下产品 Leader 与工程 Leader 及其任务，mini2 下研究 Leader 及其任务，数字未读，底部添加设备和设置。中屏：成员头像与 mini1 页头、自身消息与 Agent 消息、文件附件、待发送片段评论、可自动增高的输入框与炭墨发送按钮。右屏：mini1 设备设置、Gateway 版本待获取与检查更新、设备运行开关、Agent 与模型连接入口、选择 Leader 继续讨论配置。

约束：不添加手动创建 Task、搜索、未读筛选、固定回复按钮、点赞、角色徽标、置顶、@ 分派、未规划客户端偏好或虚构版本升级结果；忽略参考截图的蓝色评审批注与输入框外圈。

检查与边界

已目视检查生成稿的三屏内容、品牌延续、文字可读性和主要交互入口。内置浏览器不可用，参考采用原任务实际截图及本地品牌图；没有声称浏览器验证或交互测试通过。图片中的微小尺寸、线条与头像重绘偏差，后续实现应以原 SVG 资源及上述规格为准。
