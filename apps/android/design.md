# Zork Android — 当前界面基线

2026-09-07。延续移动端 nav7 的导航与对话分屏、48dp 整行触摸、44dp 独立操作区域、草稿和阅读位置保留；采用本轮确认的设置与控件修订。现有 nav7 静态原型只记录早期布局，不能覆盖本文件的新要求。

- 名称：设备 → 领队 → 任务；设置入口为「队员」「大模型」，队员页内按领队／队员分组。内部 API 标识不翻译。
- 视觉：复用共享 Zork 字体和资源；Inter 400/500/600，中文系统字体。暖白背景、白色内容、炭墨正文，绿色只表达在线或已验证，琥珀色表达待验证。
- 颜色真值：`Theme.kt`，与共享 `zork-ui` 的 Paper、Muted、Border、FieldBorder、Online、Warning 对齐；不在页面临时创建近似色。
- 几何：设置卡片 20dp 圆角、输入框 12dp、底部表单上角 32dp，按钮使用胶囊，底部表单主操作占满内容宽度；消息气泡 20dp；Composer 采用与桌面一致的暖白实色液态轮廓和 1dp 描边，外层留白 12dp；输入最多显示三行，更多内容在编辑器内部滚动，单行主体紧凑至 88dp（不含伙伴突出区域）。移动端保留至少 44dp 触摸区域，不套用桌面 32px 命中尺寸。
- 设备卡片集中名称、改名图标、连接与版本信息。手机无法修改的运行方式与登录启动不展示；后端不支持或设备离线时隐藏整个更新区，不摆灰色占位按钮和说明入口。
- 队员页使用动物头像、名字、模型与连接；按角色展示数量和职责。整行点击编辑。设置、设备、队员和大模型列表均不显示装饰性右箭头。头像和模型统一保存。
- 大模型页展示提供商标识、连接名、接入方式、模型数和验证状态。订阅授权与 API Key 分开；新连接不生成假模型。支持手动配置和获取模型 ID；未知 token 上限由用户填写，不伪造。
- 输入采用有标签的字段；秘密仅存在当前表单内存，不进入状态快照或调试输出。保存时禁用重复提交，错误留在表单中，成功后刷新所属设备。
- 导航中领队下的任务直接显示，不设置独立展开箭头。长按领队或任务打开详情底部表单，不改变普通点按和独立展开的行为。
- 不依赖 hover；底部表单使用白色不透明材质与 55% 黑色遮蔽，无背景模糊。支持系统键盘、滚动、返回关闭，保留原会话返回来源。
- 消息立即进入列表；超过一秒未 ACK 才显示发送中；失败手动重发／删除，不自动重试。重连按历史游标补齐，消息快照按变化更新。

验收使用生产 Compose 组件，在 320、375、414、768dp 宽度验证布局；底部表单必须采集其实际窗口，不能用底层 Activity 的截图代替。

## 客户端设置

- 2026-09-10 对齐当前 PC 设置：首页提供「外观」「帮助与诊断」「关于 Zork」，设备管理保留独立分组；不再设置「这台手机」和日常身份标识入口。
- 外观提供消息折叠高度：拖动示例消息底部横线，松手保存；可恢复自动，手动范围为 80–720dp。配置保存在共享 core 的本地客户端存储，只应用于这台手机；自动值为稳定的 192dp，键盘收放不重新截断消息。字号跟随系统，不提供额外字号选项。
- 连接诊断按需读取设备信息接口，显示检查时间、网络类型和各设备响应；复制报告通过白名单生成，排除名称、地址、身份、服务端原始错误与聊天内容。
- 关于显示真实客户端版本及 Zork 自身 MIT 许可，不把节点版本混作客户端版本。
- 通知需要完整后台投递能力，深色外观需要完整主题，二者当前均不展示占位入口。

## 设备设置与 PC 对齐

- 模型连接列表使用连接显示名称、提供商与验证状态，以及共享 core 归一化后的真实额度；没有额度数据不显示伪造的余额或百分比。详情支持重命名、刷新额度、更新模型及手动添加。
- 模型列表按可见项构建，显示上下文／输出上限和启用开关；缺少容量配置的模型不可直接启用。编辑支持从已有模型复制配置、K/M 容量输入、行内错误、图片读取能力和移除模型；复制不更改目标模型的 ID、默认／启用状态。
- 模型表单的操作区固定在底部，字段可独立滚动；键盘升起后仍能保存或关闭。
- 队员创建及编辑入口提供领队授权管理，保留其他设备引用，并携带原授权值提交冲突检查。
- 操作通过共享 core 的设备请求与设置投影收敛，UI 不建立第二份持久业务列表。离线继续呈现缓存，失败保留表单输入。

## Composer 伙伴状态

- 停靠头像使用共享 `avatars/portraits` 原始路径；活动伙伴从停靠列展开为带名称和状态的胶囊。
- 色彩为 Paper `#F6F5F1`、FieldBorder `#DEDFDF` 和 Ink `#24272B`；填色与描边来自同一个完整轮廓，不绘制内部接缝。
- 使用临界阻尼弹簧，目标变更保留速度；完成后显示“空闲” 1.2 秒再归位，静止时停止动画，遵循系统动画缩放设置。
- 伙伴与消息底部占位消费同一帧的位移；跟随尾部时消息同步上移，浏览历史时保持阅读锚点。附件使用独立滚动区域，不与编辑器滚动嵌套。

- Android 13 及以上直接用 AGSL 距离场绘制实色填充与等宽描边，轮廓计算不在 CPU 上逐帧生成位图遮罩。旧系统或超出 shader 成员容量时使用同几何的 CPU 路径；复用采样缓冲区、缓存不变几何，并按 0.12dp 容差简化冗余点。
- 性能回归使用 `ComposerPerformanceTest.presenceFrames`，保留设备实际像素密度，在固定对话上比较完整帧、布局、绘制与 GPU 耗时；不能用低密度模拟器的局部绘制时间代替真机结果。

- 会话优先请求设备支持的 120Hz 模式；动画仅在布局／绘制阶段读取进度，输入控件与伙伴区域分别测量。消息列表在状态切换时安排底部空间，动画帧只移动已排版的消息区域，并保留上方缓冲行，避免重复排版或露出空白。
- 状态标签复用测量结果，草稿控件、消息预览与伙伴状态分别更新。真实呈现以 FrameTimeline 验证，CPU UI 预算为 8.33ms；模拟器结果与真机结果分开。
