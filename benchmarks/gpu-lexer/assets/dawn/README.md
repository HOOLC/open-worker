# Original-model Metal shaders

Generated by Chrome for Testing 149.0.7827.55 (Dawn/Tint), from the unchanged
`gpu-lexer@0.0.2` WGSL shipped in `vendor/package/dist/index.js` (Shu Ding / quietshu,
package license MIT). The original weights remain `assets/weights.f32`.
Only the generated entry-point names are normalized to `gpu_lexer_a` … `g`.
Math, f16 storage, bounds checks and workgroup initialization remain as generated.

`experiments/dump-dawn.py` captures the compiler output using Dawn's documented
`dump_shaders` toggle. `experiments/extract-dawn.py` normalizes names and records
SHA-256 values in `checksums.json`. The original captured logs are retained.
These are offline generation tools; the Rust/Metal runtime needs no browser.

Dawn documentation: https://dawn.googlesource.com/dawn/+/refs/heads/main/docs/dawn/debugging.md
Dawn source/license: https://dawn.googlesource.com/dawn/

The host-side binding lists, storage-size metadata, workgroup sizes and memory
allocation lengths in `src/metal.rs` match these seven shader signatures.
Do not regenerate the shaders with another compiler without rechecking that ABI
and rerunning exact-label verification.
